# Simple Interest Calculator

## Description

A simple calculator to calculate simple interest based on the principal amount, rate of interest, and time.

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

If Principal = ₹10,000, Rate = 5%, and Time = 2 years:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

- Calculates simple interest
- Easy to use
- Beginner-friendly
- Provides accurate results
